# Recursos visuales

Esta carpeta contiene recursos visuales de la versión demostrativa de **Retail Sales & Cost Analytics**.

## Archivos incluidos

| Archivo | Descripción |
|---|---|
| `screenshots/dashboard-principal.png` | Captura principal del dashboard ejecutivo |
| `Retail_Sales_Cost_Analytics_DEMO.pdf` | Versión PDF del dashboard para visualización sin Excel |

## Contenido

Los recursos presentan indicadores de ventas, costos, diferencia bruta, margen estimado, rankings Top 10 y alertas comerciales utilizando datos sintéticos.

## Confidencialidad

Los recursos están destinados a la presentación pública del proyecto. No representan operaciones empresariales reales.

El dashboard funcional y sus fuentes sintéticas se encuentran en las carpetas `dashboard-demo/` y `data-demo/` del repositorio.
